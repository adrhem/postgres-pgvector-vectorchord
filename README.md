## Postgres 18 + pgvector + VectorChord

### Version

- [Postgres: 18](https://hub.docker.com/_/postgres)
- [pgvector: 0.8.6](https://github.com/pgvector/pgvector)
- [VectorChord: 1.1.1](https://github.com/supervc-stack/VectorChord)

### What's this?
This project provides a Docker setup for running Postgres 18 with the pgvector extension and VectorChord integration. I am a passionate about homelabs and it was a pain to set and mantain up different postgres versions manually that just works with [immich](https://github.com/immich-app/immich) (amazing project tbh) and other projects with my homelab setup. This project aims to simplify that process.
